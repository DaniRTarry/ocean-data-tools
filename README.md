# ocean-data-tools

Collection of Python tools for oceanographic data processing and visualisation.

| Folder | Description |
|---|---|
| [ADCP/](ADCP/) | Processing and plotting of raw ship-mounted ADCP data |
| [SWOT/](SWOT/) | Find, download and plot SWOT L3 SSH passes over a region of interest |
| [utils/](utils/) | Small helper functions: degree/km conversions, MATLAB datenum ↔ datetime, etc. |

Each folder has its own README with details and usage.

## Requirements

Python ≥ 3.10. Each tool lists its specific dependencies in its own README.
